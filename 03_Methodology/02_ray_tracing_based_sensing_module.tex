\subsection{Ray-tracing Based Sensing Module}
\label{subsec:rt_based_sensing_module}

Path solver in Sionna RT provides the path information between the transmitter and receiver based on the 3D scene environment.
It include propagation delay, channel coefficients, angle of departure (AoD), angle of arrival (AoA), and doppler shift.
